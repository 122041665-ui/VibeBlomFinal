# VibeBloom Expo

Versión Expo independiente de la app Flutter. Usa la API de producción:
`https://api.209-38-116-181.nip.io`.

## Ejecutar en el celular

1. Instala **Expo Go** en el teléfono.
2. En esta carpeta ejecuta `npm start`.
3. Escanea el QR con Expo Go (Android) o con la cámara (iPhone).

Si el teléfono no puede abrir el servidor local por la red Wi-Fi, ejecuta
`npm run start:tunnel` y vuelve a escanear el QR.

Incluye acceso, registro, invitado, sesión persistente, lugares, búsqueda,
distancia, detalle, reseñas, favoritos, comunidad, mapas externos y perfil.
